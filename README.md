# 📺 TubeClicker

**TubeClicker** é um jogo clicker temático com estética de plataforma de vídeos, desenvolvido em HTML, CSS e JavaScript — tudo em um único arquivo, direto no navegador.

## 📋 Sobre o Projeto

O **TubeClicker** é um idle/clicker game com visual inspirado em plataformas de vídeo. O objetivo é simples: clique para acumular recursos, desbloqueie melhorias e evolua seu "canal" automaticamente. Toda a lógica do jogo roda no navegador, sem necessidade de instalação ou backend.

## 📁 Estrutura do Projeto

```
TubeClicker/
└── index.html    # Jogo completo em arquivo único
```

## 🎮 Como Jogar

1. Abra o jogo no navegador
2. Clique para gerar visualizações / recursos
3. Use os recursos para comprar melhorias automáticas
4. Deixe o canal crescer sozinho enquanto o idle faz o trabalho!

## 🚀 Como Executar

```bash
# Clone o repositório
git clone https://github.com/bryanwinchezz/TubeClicker.git

# Abra no navegador
open index.html
```
